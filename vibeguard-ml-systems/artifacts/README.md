# Model artifacts

The reference model and its metrics are generated by the commands in `docs/REPRODUCIBILITY.md`. `model.pt` contains a versioned metadata record, model state dictionary, and train-fitted scaler parameters. Other JSON/CSV files are experiment reports; regenerate them when changing code, dependencies, configuration or data.

`baseline_extratrees.joblib` is only for loading the included, locally generated baseline with a trusted environment. Do not load arbitrary joblib/pickle files from untrusted sources.
