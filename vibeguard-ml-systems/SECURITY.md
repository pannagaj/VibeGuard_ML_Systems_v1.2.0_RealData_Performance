# Security policy

VibeGuard is a local portfolio/demo project. The included FastAPI service is not hardened for public internet deployment and has no built-in authentication, authorization, rate limiting, TLS, audit trail, or multi-tenant controls.

Do not put credentials, private sensor records, proprietary datasets, or sensitive operational details in issues or coding-agent prompts. For a production deployment, add an appropriate threat model, access controls, input limits, dependency scanning, observability, model-artifact provenance, and a fail-safe operating procedure.

For security-sensitive reports, contact the repository maintainer privately rather than publishing exploit details in a public issue.
